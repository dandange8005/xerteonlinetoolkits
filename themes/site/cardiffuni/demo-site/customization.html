Customization Guide

Method 1: Inline Styles

<style>
  :root {
    --cu-primary-red: #0066CC;
    --spacing-lg: 32px;
  }
</style>

Method 2: External CSS

/* custom-theme.css */
:root {
  --cu-primary-red: #2E7D32;
  --cu-forest-green: #00A86B;
}

Method 3: JavaScript

// Change dynamically
document.documentElement.style.setProperty(
  '--cu-primary-red',
  '#0066CC'
);
