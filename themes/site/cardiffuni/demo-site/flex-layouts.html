Flexbox Utilities Reference

Available utility classes for flexbox layouts.

Display

Class CSS Property Description
.flex display: flex; Creates a flex container
.inline-flex display: inline-flex; Creates an inline flex container

Flex Direction

Class CSS Property Description
.flex-row flex-direction: row; Items in a row (default)
.flex-column flex-direction: column; Items in a column
.flex-wrap flex-wrap: wrap; Items wrap to new lines

Justify Content (Horizontal Alignment)

Class CSS Property Description
.justify-start justify-content: flex-start; Align to start
.justify-center justify-content: center; Center items
.justify-end justify-content: flex-end; Align to end
.justify-between justify-content: space-between; Space between items
.justify-around justify-content: space-around; Space around items

Align Items (Vertical Alignment)

Class CSS Property Description
.items-start align-items: flex-start; Align to start
.items-center align-items: center; Center items
.items-end align-items: flex-end; Align to end
.items-baseline align-items: baseline; Align baselines
.items-stretch align-items: stretch; Stretch to fill

Gap (Spacing Between Items)

Class CSS Property Value
.gap-xs gap: var(--spacing-xs); 4px
.gap-sm gap: var(--spacing-sm); 8px
.gap-md gap: var(--spacing-md); 16px
.gap-lg gap: var(--spacing-lg); 24px
.gap-xl gap: var(--spacing-xl); 32px

Flex Items

Class CSS Property Description
.flex-1 flex: 1 1 0%; Grow and shrink equally
.flex-auto flex: 1 1 auto; Grow and shrink based on content
.flex-none flex: none; Don't grow or shrink
