Quick Start

Get started with the Cardiff University theme in minutes

1. Include the Theme CSS

<link rel="stylesheet" href="cardiffuni.css">

2. Start Using Components

<div class="card">
  <h3>Card Title</h3>
  <p>Your content here</p>
</div>

3. Customize with CSS Variables

:root {
  --cu-primary-red: #your-color;
  --spacing-md: 20px;
}

Key Features

🎯 CSS Custom Properties

Runtime customization without recompiling. Change colors, spacing, and typography on the fly.

♿ Accessible

WCAG 2.1 AA compliant with proper contrast ratios, semantic HTML, and ARIA labels.

📱 Responsive

Mobile-first design with responsive typography, spacing, and flexible layouts.

🎨 Live Theme Customizer

Adjust colors, typography, and spacing in real-time. Export your customizations as CSS.
