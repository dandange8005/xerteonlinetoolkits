Key Features

  • Runtime customization with CSS custom properties
  • Auto-generated color scales using color-mix()
  • Fluid responsive typography with clamp()
  • Comprehensive flexbox utility system
  • Cardiff University brand compliance
  • WCAG 2.1 AA accessibility

Customization Guide

Method 1: Inline Styles

<style>
  :root {
    --cu-primary-red: #0066CC;
    --spacing-lg: 32px;
  }
</style>

Method 2: External CSS

/* custom-theme.css */
:root {
  --cu-primary-red: #2E7D32;
  --cu-forest-green: #00A86B;
}

Method 3: JavaScript

// Change dynamically
document.documentElement.style.setProperty(
  '--cu-primary-red',
  '#0066CC'
);
