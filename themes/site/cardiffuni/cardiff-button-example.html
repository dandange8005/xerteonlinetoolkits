Available Modifiers

  • Variant: cu-btn--outline (optional - use for outline style buttons)
  • Color: cu-btn--primary-red, cu-btn--primary-black, cu-btn--success, cu-btn--reverse
  • Size: cu-btn--mobile, cu-btn--desktop, cu-btn--responsive (auto-adapts at 768px)
  • Icon: cu-btn--icon-left, cu-btn--icon-right, cu-btn--icon-only
  • State: Add disabled attribute for disabled state

Button Combinations

  • Filled Button: cu-btn cu-btn--primary-red cu-btn--mobile
  • Outline Button: cu-btn cu-btn--outline cu-btn--primary-red cu-btn--mobile
  • Responsive Outline: cu-btn cu-btn--outline cu-btn--success cu-btn--responsive
  • Icon Button: cu-btn cu-btn--outline cu-btn--primary-black cu-btn--desktop cu-btn--icon-only
