Details Component

Native HTML <details> disclosure widget with custom styling. Great for FAQs, expandable content, or progressive disclosure.

Details Examples

Expandable Content Blocks
What is the Details component?

The Details component is a native HTML5 element that provides a disclosure widget for showing and hiding content. It's perfect for FAQs, expandable sections, and any content that doesn't need to be visible all the time.

Click the triangle or text to expand/collapse the content.

How do I use it?

Simply wrap your content in a <details> element with the class .details. Use <summary> with class .details__summary for the clickable heading, and wrap the hidden content in a div with class .details__text.

What are the benefits?
  • Native browser support (no JavaScript required)
  • Accessible by default
  • Keyboard navigable
  • Works without CSS
  • Perfect for progressive disclosure patterns
This one is open by default

Add the open attribute to the <details> element to have it expanded by default.

Do's and Don'ts Component

Visual lists showing best practices versus things to avoid. Excellent for guidelines, tutorials, or documentation.

Examples

Best Practices Lists

Do

  • Use semantic HTML elements
  • Write descriptive alt text for images
  • Test with keyboard navigation
  • Ensure sufficient color contrast

Don't

  • Use divs for everything
  • Leave alt text empty or generic
  • Rely solely on mouse interaction
  • Use color alone to convey meaning
