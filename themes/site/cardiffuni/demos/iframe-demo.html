Custom Aspect Ratio Override

You can override aspect ratios using inline CSS custom properties:

Custom 2:1 Ratio

<div class="iframe-container" style="aspect-ratio: 2 / 1;">
Custom 2:1 Ratio

Using CSS Variable Override

<div class="iframe-container" style="aspect-ratio: var(--ratio-custom);">

Define --ratio-custom in your stylesheet or inline style.

Custom 3:2 Ratio

Browser Support

Modern Browser Support:

  • Chrome 88+ (January 2021)
  • Firefox 89+ (June 2021)
  • Safari 15+ (September 2021)
  • Edge 88+ (January 2021)

The aspect-ratio property is well-supported in all modern browsers. For legacy browser support, consider adding a fallback using padding-bottom technique.
