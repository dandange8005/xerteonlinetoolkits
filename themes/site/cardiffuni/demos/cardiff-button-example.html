Usage Examples - New Naming Convention

Basic Filled Button

<button class="button button-primary">Primary Button</button>

Outline Button

<button class="button button-primary-outline">Primary Outline</button>

Button with Right Icon

<button class="button button-primary button-icon-right">
  Next
  <span class="button__icon">
    <i class="fas fa-arrow-right"></i>
  </span>
</button>

Icon-Only Button

<button class="button button-success button-icon-only">
  <span class="button__icon">
    <i class="fas fa-check"></i>
  </span>
</button>

Available Button Variants

  • Filled Buttons:
    • button-primary - Primary action (adapts to --color-brand-primary)
    • button-secondary - Secondary action (adapts to --color-brand-secondary)
    • button-success - Success/confirmation action
    • button-reverse - Light button for dark backgrounds
  • Outline Buttons:
    • button-primary-outline
    • button-secondary-outline
    • button-success-outline
    • button-reverse-outline
  • Icon Positioning:
    • button-icon-left - Icon on the left side
    • button-icon-right - Icon on the right side
    • button-icon-only - Icon only, no text
  • State: Add disabled attribute for disabled state

Button Examples

  • Primary Filled: button button-primary

Key Features

  • ✅ Responsive by default - All buttons automatically scale from 14px (mobile) to 16px (desktop) at 768px
  • ✅ Adaptive colors - Primary and Secondary buttons adapt to your theme's brand colors
  • ✅ CSS Custom Properties - Easily customize via CSS variables
  • ✅ Accessibility - Proper focus states and disabled handling
  • ✅ Icon support - Works with Font Awesome or any icon font
