Image Alignment Classes

Pull Right (.pull-right)
Float image to the right with text wrapping
.pull-right

This paragraph demonstrates text flowing around an image that is floated to the right using the pull-right class. The image has appropriate margins to ensure proper spacing between the text and the image. This is useful for creating magazine-style layouts where images are integrated into the text content.

Additional paragraphs continue to wrap around the floated image, creating a natural and professional layout. This technique is commonly used in articles, blog posts, and educational content where visual elements need to be integrated seamlessly with text.

The pull-right class automatically adds appropriate margins and ensures the image floats correctly on all screen sizes. On mobile devices, the image may stack above the text for better readability.

Pull Left (.pull-left)
Float image to the left with text wrapping
.pull-left

This paragraph demonstrates text flowing around an image that is floated to the left using the pull-left class. Similar to the pull-right example, the image has proper margins to maintain good spacing and readability.

The text continues to flow naturally around the floated image, creating an attractive and functional layout that enhances the reading experience while showcasing relevant visual content. This is particularly effective for case studies, research articles, and instructional materials.

Both pull-left and pull-right classes are responsive and will adapt to different screen sizes, ensuring your content looks great on all devices from mobile phones to desktop computers.

The .image-full class makes images span the full width of their container. Useful for hero images, banners, and full-width visual elements.

The .image-screenshots class adds a subtle border and shadow effect, perfect for displaying software screenshots, UI mockups, or any image that should appear as a distinct visual element.

Media Best Practices

Accessibility Considerations

Images

  • Alt Text: Always provide descriptive alt text for images. Describe what the image shows, not just its filename.
  • Decorative Images: Use alt="" for purely decorative images that don't convey information.
  • Complex Images: For charts, diagrams, or infographics, provide detailed descriptions in the surrounding text or use longdesc.

Video

  • Captions: Provide captions or subtitles for all video content.
  • Transcripts: Include text transcripts for important video content.
  • Audio Description: Consider providing audio descriptions for visual content in videos.

Audio

  • Transcripts: Always provide text transcripts for audio content.
  • Controls: Ensure audio players have accessible controls.
  • Autoplay: Avoid autoplaying audio as it can be disruptive and inaccessible.
Performance Considerations
  • Image Optimization: Compress images before uploading. Use appropriate formats (JPEG for photos, PNG for graphics, SVG for icons).
  • Responsive Images: Use srcset and sizes attributes to serve appropriately sized images for different devices.
  • Lazy Loading: Use loading="lazy" attribute for images below the fold.
  • Video Hosting: Host large video files on dedicated platforms (YouTube, Vimeo) rather than your server.
  • Thumbnails: Provide poster images for videos using the poster attribute.

✓ Good Example:

<img src="campus.jpg" 
     alt="Students walking across Cardiff University campus on a sunny day" 
     loading="lazy"
     width="800" 
     height="600">

✗ Poor Example:

<img src="IMG_1234.jpg" alt="image">

This example lacks descriptive alt text, dimensions, and optimization attributes.
