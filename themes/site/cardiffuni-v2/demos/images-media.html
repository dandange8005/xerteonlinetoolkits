Icon Accessibility

Decorative Icons

Icons that are purely decorative should be hidden from screen readers:

<i class="fa-solid fa-star" aria-hidden="true"></i> Rating

Meaningful Icons

Icons that convey meaning need accessible labels:

<!-- Option 1: aria-label on the icon -->
<i class="fa-solid fa-trash" aria-label="Delete item"></i>

<!-- Option 2: Visually hidden text -->
<i class="fa-solid fa-trash" aria-hidden="true"></i>
<span class="sr-only">Delete item</span>

<!-- Option 3: aria-label on button -->
<button aria-label="Delete item">
    <i class="fa-solid fa-trash" aria-hidden="true"></i>
</button>

Best Practices

Images
  • Always provide descriptive alt text
  • Use loading="lazy" for below-fold images
  • Specify width and height
  • Use appropriate formats (JPEG, PNG, SVG)
Video
  • Provide captions/subtitles
  • Include text transcripts
  • Use poster attribute for thumbnails
  • Host large files externally
Icons
  • Use aria-hidden="true" for decorative icons
  • Add aria-label for meaningful icons
  • Use fa-fw for fixed-width alignment
  • Don't rely solely on icons for meaning

Good Example:

<button aria-label="Delete item">
    <i class="fa-solid fa-trash" aria-hidden="true"></i>
</button>

Poor Example:

<button>
    <i class="fa-solid fa-trash"></i>
</button>

Missing accessible label - screen readers won't know the button's purpose.
