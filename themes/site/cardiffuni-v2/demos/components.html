Button Usage Guidelines

When to Use Each Button Type

Primary Buttons

  • Main call-to-action on a page
  • Submit actions (forms, applications)
  • Important affirmative actions
  • Limit to one primary button per section

Secondary Buttons

  • Secondary actions that complement the primary action
  • Alternative options
  • Less critical actions

Success Buttons

  • Positive confirmations
  • Completion actions
  • Save/approve operations

Outline Buttons

  • Tertiary actions
  • Cancel or dismiss actions
  • When you need visual hierarchy with multiple buttons

Accessibility Considerations
  • Button Text: Use clear, action-oriented text ("Submit Application" not "Click Here")
  • Focus States: All buttons have visible focus indicators for keyboard navigation
  • Disabled State: Disabled buttons are visually distinct and not keyboard-focusable
  • Icon-Only Buttons: Include aria-label for screen readers when using icon-only buttons
  • Color Contrast: All button styles meet WCAG AA contrast requirements
