Form Best Practices

Accessibility Guidelines
  • Labels: Always associate labels with form fields using the for attribute and matching id.
  • Required Fields: Clearly indicate required fields with the required attribute and visual indicators.
  • Fieldsets: Group related form elements using <fieldset> and <legend>.
  • Error Messages: Provide clear, specific error messages near the relevant fields.
  • Tab Order: Ensure logical tab order for keyboard navigation.
  • Autocomplete: Use appropriate autocomplete attributes to help users fill forms faster.
Usability Tips
  • Placeholder Text: Use placeholders for examples, not instructions. Instructions should be in labels or help text.
  • Input Types: Use appropriate input types (email, tel, url, etc.) to trigger correct mobile keyboards.
  • Field Length: Make input fields an appropriate width for the expected content.
  • Validation: Provide inline validation feedback as users complete fields.
  • Submit Buttons: Use clear, action-oriented button text ("Submit Application" not just "Submit").
  • Progress Indicators: For long forms, show progress and allow saving drafts.
Form Validation

Use HTML5 validation attributes (required, pattern, min, max, etc.) for basic validation. Supplement with JavaScript for more complex validation and better user feedback.
