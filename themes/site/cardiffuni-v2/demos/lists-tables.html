How to Submit Your Assignment

  1. Log in to the student portal using your university credentials
  2. Navigate to the "Assignments" section in your course page
  3. Click on the assignment you wish to submit
  4. Prepare your submission:
    1. Ensure your document is in the correct format (PDF or DOCX)
    2. Check that your name and student ID are on the first page
    3. Verify that all required sections are complete
  5. Click the "Upload File" button and select your document
  6. Review your submission for accuracy
  7. Click "Submit" to finalize your submission
  8. Save the confirmation email for your records

Description Lists

Standard Description List
Term and definition pairs
Undergraduate
A student pursuing a bachelor's degree, typically requiring three to four years of full-time study.
Postgraduate
A student who has completed an undergraduate degree and is pursuing further education, such as a master's or doctoral degree.
Semester
An academic term, typically lasting 15-18 weeks. Most universities operate on a two-semester system (autumn and spring).
Credit Hour
A unit of measurement representing the amount of time a student spends in class per week throughout a semester.
GPA (Grade Point Average)
A numerical representation of a student's academic performance, calculated by averaging the grades earned in all courses.
Glossary Example
Using description lists for terminology

Key Terms in Computer Science

Algorithm
A step-by-step procedure or formula for solving a problem or completing a task. Algorithms are fundamental to computer programming and data processing.
API (Application Programming Interface)
A set of protocols, tools, and definitions that allows different software applications to communicate with each other.
Database
An organized collection of structured information or data, typically stored electronically in a computer system and managed by a database management system (DBMS).
Encryption
The process of converting information or data into a code to prevent unauthorized access. It is a critical component of data security.
Framework
A platform for developing software applications that provides a foundation of reusable code, libraries, and tools to streamline development.

List Utility Classes

List None (.list-none)
Removes default list styling
.list-none
  • Item with no bullets or default styling
  • Second item without markers
  • Third item in unstyled list
  • Fourth item

Useful for navigation menus, custom styled lists, or when you need list semantics without visual list styling.

Icon List (.list-icon)
Custom icon-based list styling
.list-icon
  • ✓Completed task with checkmark icon
  • ✓Another completed task
  • ✓Third completed item
  • ✓Final task in the list

The first <span> in each list item is styled as the icon. You can use any character or emoji.

Different Icons

  • →Arrow pointing to important information
  • ★Starred or featured item
  • 📝Note or documentation item
  • ⚠️Warning or caution item

Styled numbered badges

  • First step with styled number badge

Provides a more visually prominent alternative to standard ordered lists, ideal for step-by-step instructions.
