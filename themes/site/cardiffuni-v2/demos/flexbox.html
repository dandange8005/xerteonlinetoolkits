Introduction

The Cardiff University v2 theme includes a comprehensive flexbox utility system for creating responsive layouts. These utilities follow a mobile-first approach: items stack vertically on small screens and arrange horizontally on larger screens.

Key classes:

  • .flex - Creates a flex container
  • .flex-wrap - Allows items to wrap to new lines
  • .gap-* - Controls spacing between items (xs, sm, md, lg, xl, 2xl)
  • .w-* - Width utilities (w-full, w-1/2, w-1/3, w-1/4)

Flex Basis Utilities (Recommended)

How It Works

Use .flex-{size} classes to create responsive columns without inline styles. The number represents the minimum width in pixels before wrapping.

Available classes: .flex-100, .flex-150, .flex-200, .flex-250, .flex-300, .flex-350, .flex-400, .flex-500, .flex-600

Behavior: Items grow equally to fill space, but wrap when they can't maintain their minimum width.
