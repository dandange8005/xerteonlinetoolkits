Footer

An ink footer with no red. The player builds it from the project's customFooter HTML and puts it in #customFooter, so write only the columns: the theme lays them side by side and stacks them when the space is narrow. Set footerPos to replace the default footer. In that mode the player also appends its accessibility link, which the theme puts on its own row. For a logo, use an official white (reversed) version; the design system says never to recolour it.

Component Usage Guidelines

Buttons
  • Primary: Main CTA, one per section
  • Secondary: Alternative actions
  • Success: Confirmations, saves
  • Outline: Tertiary actions, cancel
Alerts
  • Success: Completed actions
  • Info: Neutral information
  • Warning: Caution needed
  • Danger: Errors, critical issues
Badges vs Labels
  • Badges: Counts, notifications
  • Labels: Categories, status tags
  • Use sparingly to avoid clutter
Accessibility
  • All components have focus states
  • Use aria-label for icon-only buttons
  • Alerts use semantic color + icons
  • Accordions use ARIA expanded states
