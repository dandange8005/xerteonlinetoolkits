Xerte Online Toolkits is a suite of browser-based tools that allow users to create interactive learning materials using simple forms-based authoring.

Component Usage Guidelines

Buttons
  • Primary: Main CTA, one per section
  • Secondary: Alternative actions
  • Success: Confirmations, saves
  • Outline: Tertiary actions, cancel
Alerts
  • Success: Completed actions
  • Info: Neutral information
  • Warning: Caution needed
  • Danger: Errors, critical issues
Badges vs Labels
  • Badges: Counts, notifications
  • Labels: Categories, status tags
  • Use sparingly to avoid clutter
Accessibility
  • All components have focus states
  • Use aria-label for icon-only buttons
  • Alerts use semantic color + icons
  • Accordions use ARIA expanded states
