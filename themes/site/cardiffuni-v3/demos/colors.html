Color Usage Guidelines

Brand Primary (Red)

Usage: Brand signals: the header’s top edge, the logo, the Warning callout; navbar and sidebar active states (pending Red Usage Decisions)

Not for: filled buttons (use --color-action, #C21F16) or error text (--color-status-error, #A11A12)

Avoid: Large background areas, body text

Brand Secondary (Dark)

Usage: Body text, secondary buttons, dark backgrounds, navigation

Avoid: Small text on colored backgrounds

Accent Colors

Usage: Sparingly, in tier order: callouts, charts, illustrations

Callouts: Information = Light Blue, Tip = Cadet, Good practice = Forest Green, Important = Yellow, Warning = Brand Red, Example = Indigo, Key point = Black (see Components)

Links: --color-link-default (#045BC6), a recorded deviation from the palette

Grayscale

Usage: Text, borders, rules and backgrounds (components are flat: no shadows)

Light grays (10-30): Backgrounds, subtle borders

Mid grays (40-60): Disabled states

Dark grays (70-90): Secondary and tertiary text (grey 70, #666666)

Accessibility & Contrast

WCAG Compliance

All color combinations in this theme meet WCAG 2.1 Level AA standards for contrast ratios:

  • Normal text: Minimum contrast ratio of 4.5:1
  • Large text (18pt+): Minimum contrast ratio of 3:1
  • UI components: Minimum contrast ratio of 3:1
Safe Color Combinations
White text on Brand Primary - WCAG AA Compliant
Primary text on White - WCAG AAA Compliant
White text on Brand Secondary - WCAG AAA Compliant
White text on Accent Green - WCAG AA Compliant
White text on Accent Navy - WCAG AA Compliant

Warning: Avoid using color alone to convey information. Always provide additional visual cues (icons, text, patterns) for users with color blindness.

Theming with CSS Custom Properties

Where the colours come from

Every colour, font family and spacing value comes from the design system’s v1/tokens.css. sync-theme.py generates scss/_cu-tokens.scss (the --cu-* tokens at :root); the theme’s --color-* roles point at those tokens. Don’t edit the generated file: change tokens.css, run sync-theme.py, then recompile the theme.

--color-action: var(--cu-action);      /* #C21F16 */
--color-focus: var(--cu-focus);        /* #121212 */
--color-link-default: var(--cu-link);  /* #045BC6 */
Creating a New Theme

Override CSS custom properties to create a new theme:

<style>
  :root {
    --color-brand-primary: #0066CC;
    --color-brand-secondary: #1A1A1A;
  }
</style>

Or use a theme selector:

[data-theme="other-uni"] {
  --color-brand-primary: #0066CC;
}
