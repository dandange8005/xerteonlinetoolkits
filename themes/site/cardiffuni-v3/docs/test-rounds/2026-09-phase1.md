## What this round changed

Checks 5, 13 and 14 were the ones that would have forced a Phase 2 rethink, and all three passed:
pasted markup survives the editor, and a project exports and re-imports intact. No fallback is needed
for the two-lane layout or the callouts.

Checks 3, 4 and 8 found real faults, all fixed and covered by new checks in `tests/check_theme.py`,
which grew from 56 to 88 checks during the round.

Two changes went beyond fixing a fault and were Nan's decisions on the day: the charcoal navbar and
the quieter selected sidebar item. Both alter where red appears and are recorded in
`Red Usage Decisions.md` in the design system.

## Follow-ups from this round

- The theme now ships `cardiffuni-v3.js`. The player already requests `<theme>/<theme>.js`, and the
  sticky page menu's height cannot be read from CSS. Without it the section menu still works; it just
  does not clear the bar or track scrolling as precisely.
- Xerte builds that script tag malformed (`'<script src="…"' + '</script>'`, missing a `>`) in
  `application.js`. jQuery still fetches and runs the file, so it works, but it is worth reporting
  upstream.


## After the round (21 September 2026)

Further testing in the player found four more faults, all fixed on the branch:

| What | Fix |
| --- | --- |
| The section menu had a fixed height with its own scrollbar, which the older theme does not do. A height cap in the theme also made the player measure the menu as short enough to pin, so it pinned where the default theme does not | `f241986` |
| Clicking a section link highlighted the section above it until the page was nudged. A link jumps before the images above the target load, so they push it below where the page stopped; the theme's smooth scrolling then made a correction animate rather than land | `7bca4f7`, simplified in `4def076` by dropping smooth scrolling |
| The theme script missed the player's own lifecycle: it never saw `contentLoaded`, and page changes use `pushState`, which fires no `hashchange`. Opening the collapsed page menu also left the measured bar height stale, and dragging the scrollbar did not stop the script re-landing the page | `79fcdeb` |
| Smooth scrolling removed, so a jump lands exactly. Readers with reduced-motion settings already had instant jumps | `4def076` |

The checks grew from 88 at the end of the round to 100 after these fixes.

The focus check now focuses the real fixture control and verifies `:focus-visible`, solid
outline, colour, width and offset without assigning an outline. It is not a manual Tab-traversal test.
Missing fixture elements now throw rather than returning the same sentinel, preventing
missing heading pairs from passing equality checks. The selected-colour comparison uses
the browser's own serialization on both sides.

The fixture now awaits asynchronous checks. It invokes the registered `contentLoaded`
handler and the registered resize observer callback, then verifies the published height.
The observer check verifies observation of both navbar candidates. Native ResizeObserver
is retained, but callback delivery is explicitly triggered for this test because Chrome's
virtual-time runner did not reliably advance compositor frames: the initial native-delivery
check failed, and waiting on an animation frame exhausted the capture budget. This is not
evidence of a player failure or a completed native-delivery integration check.

The instant-landing check also enables a host smooth-scroll override and checks that the
script restores it after correction. The fixture still stubs jQuery/scrollspy; full player,
Welsh-language and fresh standalone-export checks remain on the
[follow-up checklist](../plans/2026-09-21-follow-up.md).
