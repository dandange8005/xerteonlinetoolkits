    Let learning outcomes lead

    The menu supports discussion about how assessment helps verify learning outcomes and how AI expectations are made clear.

    Lane 1

    Use assessment where there is a need to verify core capability or intended learning outcomes.

    Lane 2

    Use assessment to support open, AI-assisted learning where that serves the learning outcomes.

    Proposed wording · for discussion

    Student choice and AI

    The two-lane approach does not assume students must use generative AI. The proposed position is that learning outcomes should remain achievable without it and students should not be disadvantaged if they choose not to use it.
