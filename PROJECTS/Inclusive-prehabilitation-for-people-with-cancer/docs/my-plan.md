My aim is to convert the content of this course into a xerte learning resource. I will start with the first module and then move on to the next modules. I will also make sure to include all the necessary information and resources for each module.

I will be using Xerte XOT template to create the resource. 

The base theme I have chosen is the "CESI" theme but I am going to make some customisation to it to make it more suitable for the content of the course. I will also be adding some custom CSS to make the resource look more visually appealing.

My plan is to create some design tokens for the project to ensure consistency in the design and to make it easier to make changes in the future.
